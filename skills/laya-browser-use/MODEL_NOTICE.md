# Bundled model notice

This skill contains the `mccoysc/xDecision` checkpoint from:

https://huggingface.co/mccoysc/xDecision

The model card declares the checkpoint under Apache License 2.0. The full license text is included
as `MODEL_LICENSE` in this directory.

xDecision is a fine-tune of `convaiinnovations/laya-multilingual` (Apache License 2.0, Convai
Innovations) over the `jhu-clsp/mmBERT-base` encoder (MIT License, Johns Hopkins University CLSP).
Its own NOTICE carries both attributions and they are preserved here.

Which checkpoint is bundled is not written into any code: it is whichever directory under
`runtime/models/` carries a `manifest.json`, and that manifest names the model.
